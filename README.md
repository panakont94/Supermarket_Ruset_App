# Supermarket Ruset - Local Vanilla JS CRM System

A fast, lightweight, dependency-free JavaScript web application for managing supermarket operations including Cash Register POS sales, Warehouse inventory tracking, and CEO executive controls.

## Features
- 🔑 **Simple Portal Login**: Pure JS credential check (`ceo`, `cashier1`, `warehouse1`).
- 🛒 **Cash Register POS**: Product search, interactive cart, payment processing (cash/card), stock validation, digital receipt.
- 📦 **Warehouse Inventory**: Real-time stock counts, cost & selling price management, expiry date warnings (expiring soon / expired badges).
- 📊 **CEO Dashboard**: Master metrics, revenue analytics, full CRUD over products, categories, user directory, and transaction logs.
- 💾 **Local Storage Persistence**: Data remains updated across browser sessions.

For full specifications and access credentials, see [SUPERMARKET_CRM_SPEC.md](./SUPERMARKET_CRM_SPEC.md).
